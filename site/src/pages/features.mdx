## Bookmark and command search

Fuzzy-search all your bookmarks and commands from one palette. The item you
want is just a few keystrokes away.

Results aren't just alphabetical. Each item is scored by how well it matches
your query and with a recency model items lose their score over time while
frequently used items get a boost. Items you use regularly stay prominent;
old favorites fade.

Open bookmarks in the current tab, in a new tab, or in a new window using
modifier keys.

See [Making the Most of Search](/hacklets/search/).

## Built-in commands

Hacklets ships with built-in commands covering tab management, zoom, and
browser utilities:

- **Tabs** — close other tabs, close tabs to the right, duplicate, detach to a
  new window, move, open incognito.
- **Zoom** — zoom in, zoom out, reset.
- **Page** — print, speed up media, open selected links, parse a selected date.
- **Hacklets** — open settings, open the script editor, reset recent items.

See the full [command reference](/hacklets/command-reference/).

## Bookmarklet runner

All `javascript:` bookmarklets you know and love are searchable via the commands
palette. Open the palette, type part of its name and hit Enter to run it.

## User Scripts

Point Hacklets at any local folder of `.js` files and every script becomes a
command. Scripts use a UserScript-style metadata header for their name, emoji,
and the pages they apply to. They execute on demand — nothing runs until you
pick it from the palette. See [Scripts](/hacklets/scripts/).

_\* Chromium-based browsers only._

## Repeat last command

Press <Shortcut combo="Cmd+." /> (Mac) or <Shortcut combo="Ctrl+." /> (Others) to re-run whatever you just executed. Handy for
commands you use in a loop, like zooming or switching tabs.

## Custom keyboard shortcuts

Bind any script or command to your own shortcut from the settings page. When
you have a command you reach for constantly, one custom binding removes the
extra keystrokes.

## Script editor

A built-in editor for creating and editing user scripts and bookmarklets —
with a file tree, syntax highlighting, and local saving. See
[Script Editor](/hacklets/script-editor/).

## New tab replacement

Hacklets also takes over the new-tab page with the bookmarks palette, so a
fresh tab is a useful search box — not a wallpaper.
