Hacklets ships with 18 built-in commands, plus the four Move Tab variants
listed under **Tabs**. Your folder scripts and bookmarklets appear alongside
these in the commands palette.

## Tabs

| Command | Emoji | What it does |
| ------- | ----- | ------------ |
| Close Other Tabs | 🗑️ | Closes every tab except the current one |
| Close Tabs to the Right | ➡️ | Closes all tabs to the right of the current one |
| Detach Tab | 📌 | Moves the current tab into its own window (⌘/Ctrl: move to the next display) |
| Duplicate Tab | 📋 | Duplicates the current tab (⌘/Ctrl: open the copy in a new window) |
| Move Tab to First | ⬅️ | Moves the current tab to the first position |
| Move Tab to Last | ➡️ | Moves the current tab to the last position |
| Move Tab to Left | ◀️ | Moves the current tab one position left |
| Move Tab to Right | ▶️ | Moves the current tab one position right |
| New Incognito Window | 🕵️ | Opens a new incognito/private window |
| Open Current Page in Incognito Window | 🕵️ | Opens the current URL in a new incognito window |

## Zoom

| Command | Emoji | What it does |
| ------- | ----- | ------------ |
| Zoom In | 🔎 | Zooms in on the current page |
| Zoom Out | 🔎 | Zooms out on the current page |
| Reset Zoom | 🔎 | Resets the zoom level to 100% |

## Page

| Command | Emoji | What it does |
| ------- | ----- | ------------ |
| Print Current Page | 🔄 | Opens the print dialog for the current page |
| Share as Markdown | 🔗 | Copies the current page title and URL as a Markdown link |
| Speed Up Media | ⏩ | Increases the playback rate of media on the page |
| Open Selected Links in New Tabs | 🔗 | Opens every link in the current selection in new tabs |
| Parse Date | 📅 | Parses a selected date string and converts it to another format |

## Hacklets

| Command | Emoji | What it does |
| ------- | ----- | ------------ |
| Hacklets: Options / Settings | 👤 | Opens the settings page |
| Hacklets: Script Editor | 👤 | Opens the script editor |
| Hacklets: Reload Extension | 👤 | Reloads the extension (after updates) |
| Reset Recent Items | 👤 | Clears the usage history that powers smart ranking |
